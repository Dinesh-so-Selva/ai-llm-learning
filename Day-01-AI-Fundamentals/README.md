# LLM API Using Python

## 🎯 Objective

Learn the fundamentals of Artificial Intelligence and Machine Learning, and understand how to connect a Python application to a Large Language Model (LLM) using an API.

## 📘 Day 1 – Topics Covered

### 1. Introduction to Machine Learning
- What Machine Learning (ML) is and why it matters.
- Difference between traditional programming and Machine Learning.

### 2. Core Concepts
- Training vs. Inference.
- Datasets: Features, Labels, and Samples.
- Model Lifecycle: Build → Train → Evaluate → Deploy.

### 3. Types of Learning
- Supervised Learning.
- Unsupervised Learning.
- Reinforcement Learning (overview).

### 4. Large Language Models (LLMs)
- What is an LLM?
- How LLMs understand and generate text.
- Real-world applications of LLMs.
- Introduction to Generative AI and Natural Language Processing (NLP).

### 5. LLM API Using Python
- What is an API?
- Connecting Python to the Google Gemini API.
- Sending questions to an LLM.
- Receiving and displaying AI-generated responses.

## 🛠️ Technologies Used

- Python
- Google Gemini API
- google-genai
- python-dotenv

## ⚙️ How It Works

1. The user enters a question.
2. Python reads the API key from the `.env` file.
3. Python sends the question to the Gemini API.
4. Gemini generates a response.
5. Python displays the answer in the terminal.
