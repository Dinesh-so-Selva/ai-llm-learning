# Day 02 - Machine Learning

## 📚 Topics Covered Today

### 1. Machine Learning Basics
- Connection between Data Science and Software Engineering.
- Training vs. Inference.
- Real-world examples: Ice cream sales, medical predictions, and penguins.

### 2. Supervised Learning
- **Regression:** Predicting numerical values, such as ice cream sales, house prices, and fuel efficiency.
- **Classification:** Predicting categories.
  - Binary classification: Diabetes risk, loan default, and marketing response.
  - Multiclass classification: Penguin species and movie genres.

### 3. Unsupervised Learning
- **Clustering:** Grouping similar data without predefined labels.
- Examples: Grouping flowers and customer segmentation.

### 4. Model Training and Evaluation

**Regression Metrics**
- MAE (Mean Absolute Error)
- MSE (Mean Squared Error)
- RMSE (Root Mean Squared Error)
- R² (Coefficient of Determination)

**Classification Metrics**
- Accuracy
- Precision
- Recall
- F1-Score
- ROC Curve and AUC
- Multiclass Confusion Matrix
- Aggregated Metrics

### 5. Deep Learning
- Artificial Neural Networks vs. Biological Neurons.
- Neural network layers and weights.
- Activation functions.
- Forward Pass and Backpropagation.
- Loss Functions and Gradient Descent.
- Epochs and Model Optimization.
- Example: Penguin species classification using a Deep Neural Network.
