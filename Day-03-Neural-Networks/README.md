# Day 3 – Neural Networks

## 🎯 Objective
Understand neural networks, activation functions, gradient descent, and model training using Python.

## 📚 Topics Covered

### 1. Neural Network Fundamentals
- What is a neural network?
- Artificial neurons and their purpose.
- Input layer, hidden layer, and output layer.
- Weights and biases.

### 2. Forward Propagation
- How input data passes through a neural network.
- How the model generates predictions.

### 3. Activation Functions
- Introduction to activation functions.
- ReLU (Rectified Linear Unit).
- ReLU returns positive values unchanged and converts negative values to zero.

### 4. Model Training
- Training data and predictions.
- Prediction errors.
- Gradient descent.
- Learning rate and epochs.
- How models learn weights and biases.

### 5. Building a Neural Network Using Python
- Used NumPy for numerical operations.
- Used Scikit-learn's MLPRegressor.
- Created a neural network with a hidden layer.
- Trained the model using house-size and house-price data.
- Predicted the price of a new house.

## 🛠️ Technologies Used
- Python
- NumPy
- Scikit-learn
- MLPRegressor
